New change
rdp-render-row.h converts8 BGRA pixels at once on ARM NEON, preserving the
exact (77R+150G+29B)>>8 and RGB565 quantization. Exact changed-pixel bounds,
partial edge tiles and alpha-ignore behavior retained. Only valid contiguous
1:1 spans use it; scaling/zoom/letterboxing retain original scalar mapping.
Non-NEON builds use exact scalar row helper. Refresh scheduling, TLS/certificate
policy, networking, profiles and input handling were NOT changed.
