# Public launch checklist

## Already in place

- [x] Product identity and one-line promise
- [x] English product website, responsive layout, metadata, and favicon
- [x] Clear compatibility and unofficial-software warnings
- [x] Community and paid offer structure
- [x] Local interest capture with explicit consent
- [x] Downloadable 1.1.3 package and SHA-256 checksum
- [x] Automated local UI/package tests and physical tablet journey
- [x] Local Git repository independent of GitHub
- [x] Deployment on Lola and entry in Lola Command Center

## Before exposing Lola to the public internet

- [ ] Buy/choose a domain and configure HTTPS
- [ ] Create a real support mailbox
- [ ] Choose merchant of record/payment provider and configure VAT handling
- [ ] Publish terms, refund policy, and final privacy notice
- [ ] Legal review of GPL source offer and reMarkable trademark wording
- [ ] Add rate limiting and backup for the interest database
- [ ] Test installation on a clean second tablet or clean firmware image
- [ ] Record the five short proof videos
- [ ] Define support response time and supported firmware matrix
