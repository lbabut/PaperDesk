Private recorded-motion preview CPU diagnostic, 24 November 2026

No installed product changes. This branch contains diagnostic tools, not a
new installable performance candidate. Do not deploy its inherited binaries.

scripts/sketch-preview-workload.py requires SHA-bound audited canvas contacts
and metadata brackets before/after each contact. Reject missing/distant or
changed settings/ranges, unknown input, nonzero preview-axis origin, eraser,
nonpositive/out-of-range pressure. Reuses all reports including stationary
coordinates. Export is private/exclusive, not published raw drawing data.
Same sampled settings do not prove no change between metadata observations.

tests/sketch-preview-workload.c includes the actual native preview source.
Calls its pressure, width, shading and segment functions on a white private
heap framebuffer and mask. Never calls the XOVI constructor, event reader,
framebuffer opener or display submission. No threads, injection or UI restart.
Three passes measure thread CPU and wall time with reset buffers; repeated
digests must match. This isolates preview pixel computation only, not the
material engine, event queue, OS scheduling, display submission or panel.
The exact material viewport/history remains unknown. This is NOT an exact
artwork replay and is not a fix or proof of responsiveness.
