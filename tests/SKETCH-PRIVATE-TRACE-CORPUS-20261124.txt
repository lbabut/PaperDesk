PRIVATE RAW TRACE SELECTION — NOT A PERFORMANCE FIX

scripts/sketch-trace-corpus.py selects explicitly audited canvas contacts from
the bounded physical capture. Selection is tied to SHA256 and exact per-contact
counts. Missing axes/tool, incomplete contacts, stream loss, reversed timestamps,
duplicate indices and count mismatch cannot silently create usable replay data.
The result preserves every accepted report, including stationary samples. It
never injects input, restarts an app, installs a module or changes artwork.
Exclusive output creation with mode0600 protects raw diagnostics from overwrite
and accidental world-readable creation. Keep output OUTSIDE public repository.

Example (paths are private inputs, not included here):
  python3 scripts/sketch-trace-corpus.py --raw events.bin \
    --selection selection.json --output private-corpus.json
Selection keys: raw_sha256, canvas_evidence, contacts:[{index,reports},...].
canvas_evidence is an operator-audited reference, NOT automatic proof that a
contact painted. The tool does not infer that every pen contact is a stroke.

Raw capture parser also resets unknown pen/rubber state after SYN_DROPPED;

Rendering replay remains explicitly NOT ready: historical viewport geometry,
axis ranges, per-contact tool settings, pressure calibration and initial material
state have not all been captured. Current settings are not substituted for
historical ones. No optical latency or exact original image reproduction claim.
