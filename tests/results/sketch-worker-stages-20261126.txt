Experimental async worker stage profiling — 26 November 2026

Scope
Base d6c513399ef7f8af56263b58a752fc78e31f771b, the existing 23 November
async research integration. This is NOT the current page-capacity UAT.
No experimental raster, RCC or ink was installed. No GUI restart/input
injection. QCoreApplication, private temporary cache/export/permit paths,
real pen/touch readers disabled explicitly.

Workload and checks
1260 synthetic charcoal samples, size38, strength1, pressure0.2..0.9,
tilt(0,-0.8), deterministic path on a white 1200x1600 page. Paced mode uses
absolute 2ms deadlines, not actual hardware input. No optical measurement.
All six ARM runs passed exact full image/material/finger and physics state
comparison with synchronous reference. Stage counters passed on host/ARM,
including accepted-job counter ownership across reset. Existing actual
advancePenInput async lifecycle/fault/nonblocking test also passed on host.

Decision
Instrumentation is suitable for further isolated research; no speed fix is
claimed and no UAT promotion. A large initial copy and whole-page first
publication are concrete next targets, but preserving loaded-page content,
ownership, save/undo barriers and current >12-page support is mandatory.
Real GUI/repaint scheduling can dominate; backend-only timing cannot explain
the previous multi-second GUI tail by itself. Existing UAT remains unchanged.
