PaperDesk 4.2.7

From source
to your tablet.

Manual installation from the project package over SSH. Source and prepared ARM files — no EXE and no from-scratch compilation.

01 · Preparation02 · Download and verify03 · SSH04 · Apps05 · Help06 · Care

Back up. Then check compatibility.

reMarkable 2 · OS 3.29.0.149 · XOVI 0.3.3 · AppLoad 0.6.0

The suite baseline is OS 3.29.0.149; Sketch is also validated on 3.29.0.153. The v4 installer accepts only these two OS versions and ARMv7 for its native material renderer. Other firmware is not validated. XOVI, AppLoad and qt-resource-rebuilder must already work. This guide does not prepare those dependencies. If missing, stop and follow their authors’ instructions for your exact firmware.

Sync or back up notebooks. Save your work and close apps. These unofficial modifications can break the interface and require manual recovery. Backups cannot guarantee recovery.

Connect a USB data cable, wake the tablet and enable the USB web interface. Find the USB management code in settings. It is the SSH password, not your PIN or Wi-Fi password. Never put it in a command.

You need a terminal with ssh, scp and tar. On Windows 10/11, check them in PowerShell; if OpenSSH Client is missing, add it through Windows Optional Features. Linux/macOS commonly include these tools. Keep Windows protection enabled.

1. Download and verify the package.

Open a terminal in a fresh working directory. Choose the block for your computer. Do not execute scripts piped directly from the internet.

Linux / macOS

curl -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.2.7.tar.gz
curl -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.2.7.tar.gz.sha256

Then verify with the command for your system:

# Linux
sha256sum -c paperdesk-sources-4.2.7.tar.gz.sha256
# macOS
shasum -a 256 -c paperdesk-sources-4.2.7.tar.gz.sha256

Windows PowerShell

curl.exe -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.2.7.tar.gz
curl.exe -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.2.7.tar.gz.sha256
Get-FileHash .\paperdesk-sources-4.2.7.tar.gz -Algorithm SHA256
Get-Content .\paperdesk-sources-4.2.7.tar.gz.sha256

On Windows, compare the ENTIRE hash in both outputs (case does not matter). On Linux/macOS, expect OK. Stop on any mismatch. A hash confirms file consistency, not publisher identity.

Extract — all systems

tar -xzf paperdesk-sources-4.2.7.tar.gz
cd paperdesk-sources-4.2.7

Review product/install.sh, product/uninstall.sh and product/MANUAL-INSTALL.md. The package contains QML/C++ source, installer source, tests, licences and prepared ARM files. It does not contain a compiler or Windows EXE.

2. Check the tablet and transfer files.

On first SSH connection, compare the fingerprint with your tablet’s independently verified, trusted key. If it unexpectedly changes, stop — do not delete known_hosts or disable verification. Enter the USB code only at the password prompt.

ssh root@10.11.99.1 'uname -m; cat /etc/os-release; df -h /home/root'
ssh root@10.11.99.1 'test -x /home/root/xovi/start && test -d /home/root/xovi/exthome/appload && test -f /home/root/xovi/extensions.d/qt-resource-rebuilder.so && echo READY'

Expect armv7l, the supported OS version and READY. Allow space for the archive, extracted files and a backup of existing apps. Without READY, or on another firmware, do not continue.

ssh root@10.11.99.1 'test ! -e /home/root/paperdesk-install-4.2.7 && mkdir -m 700 /home/root/paperdesk-install-4.2.7'
tar --exclude=paperdesk.local.conf -czf paperdesk-tablet-4.2.7.tar.gz -C product .
scp paperdesk-tablet-4.2.7.tar.gz root@10.11.99.1:/home/root/paperdesk-install-4.2.7/
ssh root@10.11.99.1 'cd /home/root/paperdesk-install-4.2.7 && tar -xzf paperdesk-tablet-4.2.7.tar.gz && sha256sum -c SHA256SUMS'

The first command deliberately refuses an existing staging directory. If it exists, stop and inspect the previous attempt; do not blindly delete it. Every checksum must say OK. File transfer uses scp, not a binary pipe, including in PowerShell.

3. Install, then start deliberately.

ssh root@10.11.99.1 'cd /home/root/paperdesk-install-4.2.7 && sh ./install.sh'
ssh root@10.11.99.1 '/home/root/xovi/start'

Run the second command only after the first succeeds. The installer backs up previous apps and retains user data. Keep the cable connected. XOVI is not started automatically at system boot. After a tablet reboot, run the second command again.

ssh root@10.11.99.1 'cat /home/root/.local/share/paperdesk/current-version'

Expected result: 4.2.7. In AppLoad, open and close all eight apps: Sketch, SSH, Web, RDP, RSS, Books, Dots and Care. Check that your notebooks remain available.

04 / Everyday use

Choose a tool for your task.

Paper Sketch — draw with dry media

Choose a pencil or charcoal and its size in the icon toolbar. Open Materials, the first icon in the middle toolbar before the 2H pencil, for the 4.1 controls:

  1. Tilt and contact: tilt the stylus to shape directional graphite or broader charcoal marks. When tilt samples are unavailable, an upright tip is used.
  2. Pen pressure: choose Calibrate pressure. On the separate white practice pad, draw several very light lines, then normal lines, then comfortably firm lines. Use Next when available and Save response to keep a valid profile. Cancel leaves the prior profile and page untouched; Reset pressure restores the standard response.
  3. Paper texture: choose Plain, Smooth or Rough. The preset changes future contact without repainting your marks. Firm strokes gradually smooth simulated tooth through burnishing.
  4. Wear: drawing gradually broadens and flattens the virtual tip. Select a pencil or charcoal and choose Sharpen tip to restore its point.
  5. Finger: blend after moving the stylus away. Touch contact geometry and motion influence the blending footprint; contact is a proxy rather than a force-sensor measurement. Clean finger clears pigment carried by the simulated fingertip.
  6. Eraser: Hard eraser rubs along the path. Kneaded eraser lifts pigment once at initial touch: lift and dab again to repeat.

Strokes start at initial pen contact. Touch and lift without moving for a dot, or move the pen to draw a line.

Done closes Materials. Full screen leaves a small menu button. Use Save to commit the sketchbook, including paper, burnishing and tip wear. Export PDF asks for a document name and adds a PDF copy to My files. After synchronization, share it from the reMarkable app. Export does not save the sketchbook. Close and page changes offer Save, Discard and Cancel.

Artwork stays in /home/root/.local/share/paperdesk/sketch through installation and removal. Back up the pre-upgrade sketchbook before its first 4.1 save if you need to return to 4.0: the older reader cannot load new v2 material pages. Calibration is stored separately when Save response is chosen.

The material model is a digital approximation. Calibration adjusts the tablet's input response; no physical-pencil matching or measured optical panel latency is claimed. The screen uses fine halftoning while saved artwork retains grayscale.

New in 4.2.3: Rapidograph draws permanent, constant-width black ink. Finger blending and graphite erasers leave ink intact. The kneaded eraser responds as you press harder and move; lift and dab again to remove another layer. Ink pages need version 4.2.3 or newer. Save before updating.

New in 4.2.4: Flip a compatible stylus to erase with its rear end using the ordinary hard eraser. Flip back to resume the selected drawing tool; its size, strength and kneaded-eraser setting are preserved. Permanent Rapidograph ink remains intact.

New in 4.2.5: The rear end uses the ordinary hard eraser at full strength even with light contact. Its response is independent of the drawing-nib pressure calibration. Hover does not erase.

New in 4.2.6: Tiny contacts and fast strokes are kept separate. Small pen reversals are no longer discarded by the previous motion threshold. Drawing, saving and export retain full quality.

New in 4.2.7: Each tool remembers its own size. The selected tool and eraser type return when the app reopens, without pressing Save. The rear eraser uses the remembered eraser width. Save still commits artwork; paper and tip wear remain part of the sketchbook.

Web — read a web page

  1. Open Web / PaperWeb in AppLoad.
  2. Tap the address field, enter a full address such as https://example.org, and open the page.
  3. Swipe with one finger to scroll. Use a two-finger gesture to change text size.
  4. Enable images when you need them. Mobile mode uses a narrow layout; Computer mode uses a desktop layout.

Tap a public HTTPS PDF or EPUB link, then choose Save to My files. You can cancel a transfer. Files are capped at 64 MB; keep at least 576 MB free before starting. The worker checks streamed size, free space and file structure before native import. Close Web and AppLoad, then open the document in My files. Archives, installers, other formats and login-only downloads are unsupported. Complex web apps, video and animations remain outside this reader’s intended use.

RSS — read news in one place

  1. Open RSS / PaperRSS and select REFRESH to download articles.
  2. Choose a source, then an article title.
  3. To add a source, choose Add feed, enter its name and RSS or Atom feed address, and save.
  4. Refresh after adding a source. Previously saved articles can also be read offline.

A feed address is not always the website's homepage address. Ask the website owner or your administrator for its RSS address if you are unsure.

Shortcuts includes F1–F12, arrows, Home/End, Page Up/Down and Shift+Tab. The desktop fits above the keyboard in both orientations. Two fingers scroll a document; spread them to zoom. Retry reconnects an interrupted session, while a changed certificate blocks it. Save and Delete wait for confirmation; errors preserve your edits.

RDP — connect to your computer

Before your first connection, ask IT for the computer address, username, domain if required, and any network access instructions. The computer must be on, support remote desktop and be reachable from your tablet.

  1. Open RDP / Remote desktop.
  2. Choose New to create a profile and enter the details from IT.
  3. Check Remember password. Turn it off if you do not want your password saved on the tablet.
  4. Choose Portrait or Landscape; start with 75% scale and 256 colours for faster updates. Save the profile, select it and tap Connect.

An e-ink screen refreshes more slowly than a monitor. Use remote desktop for steady work with text; choose lower image settings on a slow connection.

Paper Terminal

PaperDesk’s own terminal engine requires no LiTerm runtime. Saved sessions are numbered on the start screen. Double-click a session, or select it and choose Open. Use Sessions → New for the server, username and port. Password storage is optional: local files are private but unencrypted. Mouse reporting starts enabled. Shortcuts includes F1–F12 and Ctrl/Alt: tap for one use, hold to lock.

Books — a library for offline reading

In Find books, search for a title, author or research topic. Use Settings to choose languages and any of six sources: Project Gutenberg, Wolne Lektury, OpenStax, arXiv, Europe PMC and Open Library / Internet Archive. Results show their source and language; Sort by changes the order. Tap a result to download supported full text. Text editions stay in Offline shelf with saved reading positions. PDF/EPUB editions are added to the system My files; close Books and AppLoad, then open them with the built-in reader. Removing their Books shortcut does not delete the native document or annotations. Not every catalogue entry has accessible full text. Open Library is limited to unrestricted editions; arXiv entries are preprints, not necessarily peer reviewed.

Dots — a quiet game of Kropki

Choose New game to select a board size and Human or Computer for each player. Progress is saved; Undo turn takes a turn back. Play against the computer, another person, or let two computers play. Close leaves the app without deleting the game.

Care — check versions and updates

Open Care to compare INSTALLED (your current version) with LATEST (the newest version after checking for updates). Care shows changes and verifies the downloaded update before installing it. Save your work first.

After restarting the tablet: add-ons do not start automatically. If AppLoad is unavailable, start XOVI using the method configured when the tablet was prepared. Ask the person who prepared it to show you this step.

If something goes wrong

Apps disappeared after a reMarkable OS update?

Do not factory-reset the tablet or reinstall PaperDesk immediately. An OS update may reset the XOVI integration while leaving PaperDesk applications, settings and notebooks on the data partition. Keep your existing backups and start with USB/SSH access.

  1. Connect safely: attach a USB data cable, enable the tablet's USB interface and connect by SSH to root@10.11.99.1. Verify any changed SSH host-key fingerprint with the tablet itself before accepting it. Never disable host-key checking to bypass a warning.
  2. Check whether the files survived: run the read-only commands below. If current-version and the AppLoad directories exist, you may not need to reinstall PaperDesk at all.
  3. Check firmware compatibility first: after an OS update, an old XOVI/QML symbol table may be incompatible and starting XOVI can crash the interface. Verify your exact OS version against the XOVI and extension maintainers' guidance. Do not enable XOVI at boot: a broken automatic injection can leave the UI in a restart loop.
  4. Recover the XOVI integration only when compatible: back up the tablet, keep USB/SSH available, and follow the XOVI maintainer's process for rebuilding its QML hash table if required. That process temporarily stops the main interface and can require unlocking the tablet. Once the rebuild finishes successfully, start XOVI manually (command below).
  5. Reinstall PaperDesk only if its app files are actually missing: after restoring and verifying XOVI + AppLoad, follow the manual installation procedure for a supported version, keeping your existing /home/root/.local/share/paperdesk backups. Do not erase the data directory.
ssh root@10.11.99.1 'cat /etc/os-release; cat /home/root/.local/share/paperdesk/current-version; ls /home/root/xovi/exthome/appload'
# Only after confirming XOVI compatibility / rebuilding its hash table:
ssh root@10.11.99.1 '/home/root/xovi/start'

For firmware-specific rebuild instructions, see XOVI extensions and recovery documentation ↗. If you cannot reach USB/SSH or the tablet bootloops, stop and seek model-specific recovery assistance; reMarkable 2 recovery may require a pogo-pin adapter. No recovery procedure is guaranteed.

Installation or connection errors

Do not blindly repeat an installation. Record the exact error, check USB cable, tablet wake state, address and management code. Preserve the existing backups in /home/root/.local/share/paperdesk.

Updates and removal

Care offers the signed 4.2.7 update directly. Save work, check the version and release notes, then confirm. Remove PaperDesk removes apps but retains data and backups. Alternatively, use the commands below.

ssh root@10.11.99.1 'sh /home/root/paperdesk-install-4.2.7/uninstall.sh'
ssh root@10.11.99.1 '/home/root/xovi/start'

Do not delete the state directory: it holds backups. On a very old installation without an original LiTerm snapshot, removal cannot reconstruct files that were never saved.
