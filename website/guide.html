Ręczna instalacja z paczki projektu przez SSH. Kod i przygotowane pliki ARM — bez EXE i bez kompilowania od zera.

01 · Przygotowanie02 · Pobierz i sprawdź03 · SSH04 · Aplikacje05 · Pomoc06 · Care

Najpierw kopia i zgodność.

reMarkable 2 · OS 3.29.0.149 · XOVI 0.3.3 · AppLoad 0.6.0 · LiTerm 0.1.7

Bazowa konfiguracja pakietu była testowana na OS 3.29.0.149; Sketch także na 3.29.0.153. Instalator v4 dopuszcza tylko te dwie wersje i ARMv7 ze względu na natywny moduł materiałów. Inne firmware nie zostało zweryfikowane. XOVI, AppLoad, LiTerm i qt-resource-rebuilder muszą już działać. Ta instrukcja nie przygotowuje tych zależności. Jeśli ich brakuje, zatrzymaj się i skorzystaj z instrukcji ich autorów dla dokładnie Twojego firmware.

Zsynchronizuj lub wykonaj kopię notatek. Zapisz pracę i zamknij aplikacje. Modyfikacje są nieoficjalne, mogą spowodować awarię interfejsu i wymagać ręcznego odzyskiwania. Kopie nie gwarantują odzyskania danych.

Podłącz kabel USB z transmisją danych, wybudź tablet i włącz interfejs WWW przez USB. Odczytaj kod zarządzania USB w ustawieniach. Jest hasłem SSH, nie kodem PIN ani hasłem Wi-Fi. Nie wpisuj go w polecenia.

Potrzebujesz terminala oraz ssh, scp i tar. W Windows 10/11 sprawdź je w PowerShell; jeśli brakuje OpenSSH Client, dodaj go przez systemowe Funkcje opcjonalne. Linux/macOS zwykle mają te narzędzia. Nie wyłączaj ochrony Windows.

1. Pobierz i zweryfikuj paczkę.

Otwórz terminal w nowym katalogu roboczym. Uruchom blok odpowiedni dla systemu. Nie wykonuj skryptów pobieranych bezpośrednio z internetu.

Linux / macOS

curl -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.0.0.tar.gz
curl -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.0.0.tar.gz.sha256

Następnie sprawdź sumę poleceniem dla swojego systemu:

# Linux
sha256sum -c paperdesk-sources-4.0.0.tar.gz.sha256
# macOS
shasum -a 256 -c paperdesk-sources-4.0.0.tar.gz.sha256

Windows PowerShell

curl.exe -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.0.0.tar.gz
curl.exe -fLO https://paperdesk.lukaszbabut.info/download/paperdesk-sources-4.0.0.tar.gz.sha256
Get-FileHash .\paperdesk-sources-4.0.0.tar.gz -Algorithm SHA256
Get-Content .\paperdesk-sources-4.0.0.tar.gz.sha256

W Windows porównaj CAŁY hash z obu wyników (wielkość liter nie ma znaczenia). W Linux/macOS oczekuj OK. Przy różnicy zatrzymaj się. Hash potwierdza zgodność plików, nie tożsamość autora.

Rozpakuj — wszystkie systemy

tar -xzf paperdesk-sources-4.0.0.tar.gz
cd paperdesk-sources-4.0.0

Przejrzyj product/install.sh, product/uninstall.sh i product/MANUAL-INSTALL.md. Paczka zawiera źródła QML/C++, kod instalatorów, testy, licencje i gotowe pliki ARM. Nie zawiera kompilatora ani Windows EXE.

2. Sprawdź tablet i skopiuj pliki.

Przy pierwszym SSH porównaj fingerprint klucza z zaufanym, niezależnie potwierdzonym kluczem tabletu. Jeśli klucz niespodziewanie się zmienił, przerwij — nie usuwaj known_hosts i nie wyłączaj weryfikacji. Wpisz kod USB dopiero w zapytaniu o hasło.

ssh root@10.11.99.1 'uname -m; cat /etc/os-release; df -h /home/root'
ssh root@10.11.99.1 'test -x /home/root/xovi/start && test -d /home/root/xovi/exthome/appload/literm && test -f /home/root/xovi/extensions.d/qt-resource-rebuilder.so && echo READY'

Oczekuj armv7l, właściwej wersji OS i READY. Sprawdź wolne miejsce: potrzebne są paczka, rozpakowane pliki oraz kopia istniejących aplikacji. Bez READY lub przy niewłaściwej wersji nie idź dalej.

ssh root@10.11.99.1 'test ! -e /home/root/paperdesk-install-4.0.0 && mkdir -m 700 /home/root/paperdesk-install-4.0.0'
tar --exclude=paperdesk.local.conf -czf paperdesk-tablet-4.0.0.tar.gz -C product .
scp paperdesk-tablet-4.0.0.tar.gz root@10.11.99.1:/home/root/paperdesk-install-4.0.0/
ssh root@10.11.99.1 'cd /home/root/paperdesk-install-4.0.0 && tar -xzf paperdesk-tablet-4.0.0.tar.gz && sha256sum -c SHA256SUMS'

Pierwsze polecenie celowo odmawia użycia istniejącego katalogu. Jeśli już istnieje, zatrzymaj się i sprawdź poprzednią próbę; nie kasuj go w ciemno. Każda suma kontrolna musi dać OK. Używamy pliku i scp zamiast binarnego potoku, również dla PowerShell.

3. Zainstaluj i uruchom świadomie.

ssh root@10.11.99.1 'cd /home/root/paperdesk-install-4.0.0 && sh ./install.sh'
ssh root@10.11.99.1 '/home/root/xovi/start'

Kontynuuj po sukcesie pierwszego polecenia. Instalator tworzy kopię wcześniejszych aplikacji; nie usuwa danych użytkownika. Nie odłączaj kabla. XOVI nie jest uruchamiane automatycznie przy starcie systemu. Po restarcie tabletu uruchom drugie polecenie ponownie.

ssh root@10.11.99.1 'cat /home/root/.local/share/paperdesk/current-version'

Wynik: 4.0.0. W AppLoad otwórz i zamknij każdą z ośmiu aplikacji: Sketch, SSH, Web, RDP, RSS, Books, Dots, Care. Sprawdź, czy Twoje notatniki są nadal dostępne.

04 / Codzienna praca

Wybierz narzędzie do zadania.

Paper Sketch — ołówek, węgiel i papier

Wybierz grafit lub węgiel i ustaw rozmiar suwakiem w pasku ikon. Nacisk rysika zmienia kontakt i ilość pigmentu. Rozcieraj luźny pigment palcem po odsunięciu rysika; gumka podnosi pigment. Pełny ekran pozostawia mały przycisk menu. Save zapisuje szkicownik. Export PNG pyta o nazwę i zapisuje obraz w skali szarości w Documents, ale nie zapisuje szkicownika. Zamknięcie i zmiana strony dają wybór Save, Discard i Cancel. Rysunki w /home/root/.local/share/paperdesk/sketch pozostają po aktualizacji i odinstalowaniu. To cyfrowe przybliżenie materiałów: ekran używa drobnego rastrowania, zapisane rysunki zachowują skalę szarości.

Web — przeczytaj stronę internetową

  1. Otwórz Web / PaperWeb w AppLoad.
  2. Dotknij pola adresu i wpisz pełny adres, np. https://example.org. Zatwierdź otwarcie strony.
  3. Przesuwaj jednym palcem, aby czytać dalej. Gest dwoma palcami zmienia wielkość tekstu.
  4. Włącz obrazy, jeśli są potrzebne. Tryb Mobile pomaga na stronach z wąskim układem; Computer wybiera układ komputerowy.

Dotknij publicznego linku HTTPS do PDF lub EPUB i wybierz Save to My files. Pobieranie można anulować. Limit pliku wynosi 64 MB; przed rozpoczęciem potrzeba co najmniej 576 MB wolnego miejsca. Proces pobierania kontroluje rozmiar, wolne miejsce i strukturę pliku przed importem. Zamknij Web i AppLoad, a dokument otwórz w systemowym My files. Archiwa, instalatory, inne formaty i pobieranie wymagające logowania nie są obsługiwane. Rozbudowane aplikacje internetowe, filmy i animacje nadal nie są przeznaczeniem tego czytnika.

RSS — czytaj wiadomości w jednym miejscu

  1. Otwórz RSS / PaperRSS i wybierz REFRESH, aby pobrać artykuły.
  2. Wybierz źródło, a następnie tytuł artykułu.
  3. Aby dodać źródło, użyj Add feed, wpisz jego nazwę i adres kanału RSS lub Atom, a potem zapisz.
  4. Odśwież listę po dodaniu źródła. Zapisane artykuły możesz czytać również bez internetu.

Adres kanału nie zawsze jest adresem strony głównej. Jeśli nie wiesz, jaki wpisać, poproś właściciela strony lub administratora o adres RSS.

RDP — połącz się ze swoim komputerem

Przed pierwszym połączeniem poproś dział IT o adres komputera, nazwę użytkownika, ewentualną domenę i wymagany sposób dostępu do sieci. Komputer musi być włączony, obsługiwać zdalny pulpit i być osiągalny z tabletu.

  1. Otwórz RDP / Remote desktop.
  2. Utwórz profil przez New i wpisz dane otrzymane od IT.
  3. Sprawdź ustawienie Remember password. Wyłącz je, jeśli nie chcesz zapisywać hasła na tablecie.
  4. Wybierz Portrait lub Landscape; dla szybszej pracy zacznij od skali 75% i 256 kolorów. Zapisz profil, wybierz go z listy i dotknij Connect.

Ekran e-ink odświeża się wolniej niż monitor. Używaj tego połączenia do spokojnej pracy z tekstem; przy wolnym połączeniu wybierz niższe ustawienia obrazu.

PaperDesk SSH — narzędzie dla administratora

PaperDesk SSH służy do połączeń SSH i wykonywania komend. Jeśli Twoja praca tego nie wymaga, możesz go pominąć. Do pierwszego połączenia potrzebujesz danych serwera i instrukcji od administratora. W Sessions → New zapisz serwer, login i port. Zaznacz zapisane połączenie i użyj Open, Edit lub Delete. Hasła wpisujesz podczas łączenia — SSH ich nie zapisuje. Nie wklejaj nieznanych komend.

Books — książki i nauka offline

W Find books szukaj tytułu, autora lub tematu. W Settings wybierz języki i dowolne z sześciu źródeł: Project Gutenberg, Wolne Lektury, OpenStax, arXiv, Europe PMC oraz Open Library / Internet Archive. Wyniki wskazują serwis i język; Sort by zmienia kolejność. Dotknij wyniku, aby pobrać obsługiwaną pełną treść. Wersje tekstowe znajdziesz w Offline shelf z zapamiętanym miejscem czytania. PDF i EPUB trafiają do systemowego My files: zamknij Books oraz AppLoad i otwórz dokument fabrycznym czytnikiem. Usunięcie skrótu w Books nie kasuje systemowego dokumentu ani adnotacji. Nie każda pozycja katalogu ma dostępną pełną treść. Open Library udostępnia tylko pozycje bez ograniczeń dostępu; prace arXiv to preprinty, niekoniecznie recenzowane.

Dots — chwila na Kropki

New game pozwala wybrać rozmiar planszy oraz Human lub Computer dla każdego gracza. Gra zapisuje postęp; Undo turn cofa turę. Możesz grać z komputerem, z drugą osobą lub obserwować dwa komputery. Close zamyka aplikację bez usuwania partii.

Care — sprawdź wersję i aktualizacje

Otwórz Care, aby porównać INSTALLED (zainstalowana wersja) i LATEST (najnowsza wersja po sprawdzeniu aktualizacji). Care pokazuje zmiany i weryfikuje pobraną aktualizację przed instalacją. Zapisz pracę przed aktualizowaniem.

Po ponownym uruchomieniu tabletu: dodatki nie startują automatycznie. Jeśli AppLoad nie jest dostępny, uruchom XOVI w sposób ustawiony podczas przygotowania tabletu. Osoba, która go przygotowała, powinna pokazać Ci ten krok.

Gdy coś pójdzie nie tak

Aplikacje zniknęły po aktualizacji reMarkable OS?

Nie przywracaj ustawień fabrycznych ani od razu nie reinstaluj PaperDesk. Aktualizacja może wyłączyć integrację XOVI, choć aplikacje, ustawienia i notatki nadal są na partycji danych. Zachowaj kopie i zacznij od dostępu przez USB/SSH.

  1. Podłącz się bezpiecznie: użyj kabla USB z transmisją danych, włącz interfejs USB tabletu i połącz się przez SSH z root@10.11.99.1. Zmianę odcisku klucza SSH zweryfikuj niezależnie z tabletem. Nie wyłączaj sprawdzania kluczy, żeby ominąć ostrzeżenie.
  2. Sprawdź, czy pliki ocalały: wykonaj poniższe polecenia tylko do odczytu. Jeśli current-version i katalogi AppLoad istnieją, reinstalacja PaperDesk może nie być potrzebna.
  3. Najpierw sprawdź zgodność firmware: po aktualizacji stara tablica symboli XOVI/QML może powodować awarię interfejsu. Porównaj wersję systemu z instrukcjami autorów XOVI i rozszerzeń. Nie włączaj autostartu XOVI — niezgodna automatyczna integracja może wywołać pętlę restartów interfejsu.
  4. Przywróć XOVI dopiero po potwierdzeniu zgodności: zrób kopię danych, pozostaw USB/SSH dostępne i zgodnie z instrukcjami autorów XOVI przebuduj tablicę QML, jeśli jest to potrzebne. Ten proces chwilowo zatrzymuje interfejs i może wymagać odblokowania tabletu. Po pomyślnym zakończeniu uruchom XOVI ręcznie (polecenie poniżej).
  5. Przeinstaluj PaperDesk tylko, jeśli plików aplikacji rzeczywiście brakuje: po przywróceniu i sprawdzeniu XOVI + AppLoad wykonaj instrukcję ręcznej instalacji dla zgodnej wersji, zachowując kopie w /home/root/.local/share/paperdesk. Nie usuwaj katalogu danych.
ssh root@10.11.99.1 'cat /etc/os-release; cat /home/root/.local/share/paperdesk/current-version; ls /home/root/xovi/exthome/appload'
# Dopiero po sprawdzeniu zgodności XOVI / przebudowaniu tablicy:
ssh root@10.11.99.1 '/home/root/xovi/start'

Dokładną procedurę przebudowy dla danej wersji firmware znajdziesz w dokumentacji rozszerzeń XOVI i odzyskiwania ↗. Jeśli USB/SSH nie działa albo tablet wpada w pętlę restartów, przerwij próby i skorzystaj z pomocy przy odzyskiwaniu danego modelu; reMarkable 2 może wymagać adaptera pogo-pin. Nie ma gwarantowanej metody naprawy.

Błędy instalacji lub połączenia

Nie ponawiaj instalacji w ciemno. Zapisz dokładny błąd, sprawdź kabel USB, wybudzenie, adres i kod zarządzania. Zachowaj kopie w /home/root/.local/share/paperdesk.

Aktualizacje i odinstalowanie

Care pobiera podpisaną aktualizację 4.0.0 bezpośrednio. Zapisz pracę, sprawdź wersję i release notes, dopiero potem potwierdź. Remove PaperDesk usuwa aplikacje, ale zachowuje dane i kopie. Alternatywnie użyj poniższych poleceń.

ssh root@10.11.99.1 'sh /home/root/paperdesk-install-4.0.0/uninstall.sh'
ssh root@10.11.99.1 '/home/root/xovi/start'

Nie usuwaj katalogu stanu: zawiera kopie. Przy bardzo starej instalacji bez oryginalnego LiTerm odinstalowanie nie odtworzy plików, których nigdy nie zachowano.
