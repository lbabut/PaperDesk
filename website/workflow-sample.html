Free workflow sample / v0.1

One task.
One finish line.

A two-page worksheet to define a small task, choose a tool that already works, and record the result. Try it on paper or in your existing reader. No tablet changes needed.

Download the free PDF Share feedback on GitHub

2 pages, A4, English. No purchase, reservation, email registration or account is needed to download. GitHub feedback requires a GitHub account and is public.

A small experiment

  1. Choose one task you already know how to do safely.
  2. Use the worksheet during one short session.
  3. Tell us what helped, what did not, and what needs to change.

Useful feedback, not praise

We want to know whether a practical companion adds anything beyond the existing free manuals. “It did not help” is a useful answer too.

Do not post passwords, keys, private screenshots, notebooks or personal account details in a GitHub issue.

A preview, not a paid product. No paid pack is currently available. This is not an installation guide or a compatibility certificate. Full device workflow tests and demonstrations are unfinished. PaperDesk and its existing manuals remain free.
