Paper Sketch joins PaperDesk: graphite, charcoal, a pigment-lifting eraser, textured paper and pressure-sensitive marks with finger blending.
Drawing actions use icons, with tool size in the same toolbar and more space for the page. Tap a tool, choose its size and draw; finger blending is available away from the stylus.
Save the sketchbook manually or export full-grayscale PNGs to Documents. Installation retains existing sketches, settings and exports.
The installer checks the explicitly supported reMarkable OS 3.29.0.149 or 3.29.0.153 / ARMv7 environment before installing the native material renderer, backs up any existing renderer and preserves the prior module for removal.
All eight apps are included. Source code is available at https://github.com/lbabut/PaperDesk. The material model approximates dry media; software regression results do not measure physical pen-to-panel latency.
