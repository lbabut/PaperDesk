# Licensing map

PaperDesk is a commercially distributable open-source bundle. Charging for a
copy, installation, updates, testing, or support does not remove the licence
rights of recipients.

The repository contains components under different licences:

- LiTerm-derived frontend: GNU GPL v2; see `product/licenses/LiTerm-GPL-2.0.txt`.
- AppLoad compatibility QML and QTFB shim: GNU GPL v3; see
  `product/licenses/AppLoad-GPL-3.0.txt` and `product/third_party_source/`.
- Paper Sketch's optional legacy pen-preview extension derives from David
  @ TheoryStudios' RemarkableAnimator and retains its MIT notice at
  `product/payload/apps/papersketch/native/LICENSE`. This optional extension is
  not installed by the normal v4 package. Its MIT notice should not be read as a
  separate licence grant for all original Paper Sketch code.
- Paper Sketch's original QML/JavaScript UI, C++ material renderer and supporting
  tests/build scripts are included as corresponding source. They have no
  separate explicit licence declaration in the imported development baseline;
  the existing PaperDesk policy above/below does not identify a standalone
  licence for them. Public GitHub availability alone does not add one.
- FreeRDP runtime integration: Apache License 2.0; see
  `product/licenses/FreeRDP-Apache-2.0.txt`.
- Original PaperDesk application code is distributed with the corresponding
  source in `product/payload/apps/` and must retain the applicable notices of
  the component it integrates with.
- Website copy, identity, and marketing assets are copyright PaperDesk and are
  not included in the software licence grant unless stated otherwise.
- PaperDesk Books bundles the complete English text of *The Iliad*,
  translated by Samuel Butler (Project Gutenberg eBook #2199). Its full
  Project Gutenberg notices and license are included in the bundled text.
  The source page describes this edition as public domain in the USA;
  users outside the USA should check local copyright rules.

Before a public paid launch, have counsel verify the final source-offer,
trademark, consumer-rights, tax, and privacy wording for the countries sold to.
This file is a project map, not legal advice.
